====================================
 HOW TO START - ONLY 2 STEPS
====================================

STEP 1:  Extract the zip file
         (Right-click on zip -> Extract All)

STEP 2:  Go inside the extracted folder
         and double-click  OptionChain.exe

THAT'S IT!

*  All 3 Excel files open automatically
      (btc_chain.xlsx, eth_chain.xlsx, xaut_chain.xlsx)
   *  Please WAIT 1-2 MINUTES before checking.
      The tool activates, connects to the exchange and
      loads all three markets before the first numbers
      appear. This is normal, not a hang.
   *  Once the BTC price in the top-left cell starts
      changing, everything is working
   *  To stop: just close Excel


====================================
 COMMON QUESTIONS
====================================

Q: Excel files are ALREADY open. Can I still run OptionChain.exe?
A: YES! Just double-click it. The tool connects to the
   open sheets and starts updating them right away.

Q: I closed Excel. How do I start again?
A: Simply double-click OptionChain.exe again.
   (No need to restart laptop or install anything.)

Q: "Windows protected your PC" message appears?
A: Click  "More info"  ->  "Run anyway".
   This is normal for new programs.

Q: Data is not updating?
A: Wait 1-2 minutes first - it needs time to connect.
   Still blank after 2 minutes?
   Check your internet connection, then close Excel
   and run OptionChain.exe again.

Q: The sheets opened but everything says "--"?
A: The top-left cell shows the BTC price. Once THAT
   number starts changing, the chain has loaded.
   If it never changes, run OptionChain.exe again.

Q: How often does the price change?
A: The price refreshes several times per second, but
   the exchange itself publishes a new index value
   every few seconds. So the number updates in steps -
   that is the exchange, not a fault.

Q: Do I need to install Python or anything else?
A: NO. Everything is packed inside OptionChain.exe.
   Only Microsoft Excel must be installed on the laptop.

Q: "Product Key" popup appears?
A: Every month needs a new key (first run too).
   Key stays valid till the last Friday of the
   month - ask the owner for the current key,
   type it in, and the tool continues.

 QUICK TIPS

 Change strike count : edit A2            (e.g. 20)
 Yellow row = ATM | Green = ITM calls | Red = ITM puts
