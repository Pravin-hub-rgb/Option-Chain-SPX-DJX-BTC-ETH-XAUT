====================================
 DELTA OPTION CHAIN - SETUP GUIDE
====================================

BEFORE YOU START
------------------------------------
This tool ships as a FOLDER, not a single file.
The OptionChain folder contains ~2,000 support files
that it needs to run. Please do not move the EXE out
of that folder.


====================================
 STEP 1 - UNBLOCK THE ZIP
====================================

Windows marks downloaded files as "blocked". This
stops the tool from starting.

1. Right-click the ZIP file  ->  Properties
2. At the bottom, tick the box:
       [x]  Unblock
3. Click  Apply, then  OK

Skip this and Windows may refuse to run the tool.


====================================
 STEP 2 - EXTRACT THE WHOLE ZIP
====================================

1. Right-click the ZIP  ->  Extract All...
2. Choose a plain folder, for example  C:\DeltaChain

IMPORTANT: do NOT run the tool from inside the ZIP.
Right-click -> Open, or double-click the ZIP in the
explorer, and the EXE will not find its support files.

After extracting you should see:

   C:\DeltaChain\OptionChain\
       OptionChain.exe
       btc_chain.xlsx
       eth_chain.xlsx
       xaut_chain.xlsx
       config.json
       README.txt
       _internal\        <- this folder is required


====================================
 STEP 3 - CREATE A SHORTCUT
====================================

1. Open  C:\DeltaChain\OptionChain
2. Right-click  OptionChain.exe  ->  Send to
   ->  Desktop (create shortcut)
3. Use that shortcut from now on

Always start the tool from the shortcut or from
inside the OptionChain folder - never from a
different location.


====================================
 STEP 4 - RUN IT
====================================

Double-click  OptionChain.exe

*  A "Product Key" box appears on first run.
   Enter the key from the owner. The key stays
   valid till the last Friday of that month.

*  All three Excel files open automatically.

*  PLEASE WAIT 1-2 MINUTES before checking.
   The tool connects to the exchange and loads all
   three markets before the first numbers appear.
   This is normal, not a hang.

*  Once the BTC price in the top-left cell starts
   changing, everything is working.

*  Closing Excel only PAUSES the writes. The tool stays
   running and carries on by itself as soon as you reopen
   the workbooks. To stop it for good, open Task Manager,
   find OptionChain.exe and choose End task.


====================================
 COMMON QUESTIONS
====================================

Q: "Windows protected your PC" message?
A: Click "More info" -> "Run anyway".
   This is normal for any new program.

Q: Do I need to install Python or anything?
A: NO. Everything is inside the OptionChain folder.
   Only Microsoft Excel must be installed.

Q: Excel is ALREADY open. Can I still start it?
A: YES. Just start the tool and it attaches to the
   open sheets.

Q: I closed Excel. How do I start again?
A: Just reopen the workbooks. The tool never stopped - it waits
   and refills them by itself within a few seconds. Only run
   OptionChain.exe again if Excel is not already open.

Q: Sheets are blank or show "--"?
A: Wait 1-2 minutes first. Still blank after that?
   Check the internet connection, reopen the chain workbooks,
   and give it another minute.

Q: How often does the price change?
A: The tool refreshes about once per second. The
   exchange itself publishes a new index value every
   few seconds, so the number moves in steps. That
   is the exchange's feed, not a fault in the tool.

Q: An Excel add-in error appears on startup
   (for example a ".xll" file name)?
A: That is NOT from this tool. This package contains
   no .xll add-in. It comes from other software
   already installed on that computer.
   To remove it:
     Excel -> File -> Options -> Add-ins
     -> Manage: Excel Add-ins -> Go
     -> untick the offending add-in -> OK
   Or remove its startup entry from
     %appdata%\Microsoft\Excel\XLSTART

Q: Where are the logs?
A: C:\Users\<your name>\AppData\Local\DeltaOptionChain
   - startup_diag.log  (system and Excel details)
   - app.log           (errors, if any)
   Send these to the owner if something is wrong.
